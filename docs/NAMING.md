# Naming review

This is a risk record, not legal advice or a trademark clearance opinion.

## Current decision

Ravenhill remains the project name. It was selected as a literary-inspired
name and overlaps a place name in J.R.R. Tolkien's fiction. The maintainer has
not approved a rename, and this review does not perform one.

The name is not treated as cleared merely because the source will be free of
other Tolkien-derived names and artwork. No comprehensive federal, state,
common-law, domain, package-registry, international, or product-class search
has been completed.

## Removed direct references

The former storage nickname, mountain/gate filenames and artwork, and
24-character privacy alias list were direct or strongly thematic Tolkien
references. They have been removed from the application candidate. Public mode
now uses a manually selected list of 24 common botanical names, and the storage
panel uses an original abstract storage-array SVG.

Private operational history may still describe the former names because it is
historical evidence; it is not application documentation or a release input.

## Risk and recommendation

The Tolkien Estate's [official FAQ](https://www.tolkienestate.com/frequently-asked-questions-and-links/)
documents active copyright and trademark policies. It does not specifically
clear or forbid this software name, so it cannot be used as permission.

The US Patent and Trademark Office explains that a meaningful clearance search
must consider confusingly similar marks and related goods/services, and that a
federal database search is only one part of a comprehensive search. See its
[federal searching guidance](https://www.uspto.gov/trademarks/search/federal-trademark-searching)
and [similar-mark guidance](https://www.uspto.gov/trademarks/basics/why-search-similar-trademarks).

Before changing repository visibility or publishing packages or images under
this name, the maintainer should:

1. obtain a comprehensive clearance review for the intended software name,
   logo, goods/services, and release jurisdictions;
2. search software repositories, package registries, domains, and unregistered
   commercial uses in addition to formal trademark databases;
3. decide explicitly whether to retain Ravenhill or approve a neutral rename;
4. keep a neutral fallback name available until that decision is recorded; and
5. avoid adding Tolkien character, place, title, quotation, or artwork themes
   to the application or its release branding.

Status: **unresolved naming risk; Ravenhill retained pending an explicit
maintainer decision.** This status does not block repository-only engineering,
but it must be revisited before public branding or artifact publication.
